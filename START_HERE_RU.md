# Запуск RecoGo

## Самый простой способ — Windows

1. Распакуйте весь архив в отдельную папку, например `C:\Projects\RecoGo`.
2. Запустите `start_local.bat`.
3. Откроется отдельное окно сервера, загрузятся 290 синтетических событий, создастся модель, откроется браузер.
4. В панели запросите рекомендации для `user-001`. Для нового пользователя, например `new-user`, будут показаны популярные товары.
5. Для обучения и выбора версии введите административный токен `recogo-local`.

Приложен готовый Windows x64 exe, Go устанавливать не обязательно. Локальный режим работает без Kafka, Docker, Airflow и MLflow: события сохраняются напрямую в bbolt. Для полного стека используйте следующий раздел.

Сервер должен оставаться запущенным. Остановить — Ctrl+C в его окне. Файлы данных сохраняются в `var`; повторный запуск их не удаляет. Демонстрационные ID стабильны в пределах суток: повторная загрузка в тот же день не размножает события. На следующие сутки генератор создаёт новую партию синтетики.

Если Windows предлагает предупреждение о неизвестном издателе, учтите: бинарник не подписан. Можно самостоятельно собрать его из исходников с установленным Go: `go build -o bin\recogo-windows-amd64.exe ./cmd/recogo`.

## Docker — Kafka + Go + MLflow

1. Запустите Docker Desktop с Linux-контейнерами. Нужны интернет для первой сборки и свободные ресурсы; ориентир — от 4 ГБ доступной RAM, это не результат ресурсного теста.
2. Остановите локальный сервер, если он уже занимает порт 8080.
3. Запустите `start_docker.bat` и дождитесь завершения сборки и обучения.
4. Откройте http://127.0.0.1:8080 и http://127.0.0.1:5000.

Остановка: `docker compose down`. Данные сохраняются в Docker volumes. Следующий запуск: `docker compose up -d --wait api`.

Параметры можно задать в `.env`, скопировав `.env.example`. Токен демонстрационный. По умолчанию HTTP-порты опубликованы только на 127.0.0.1.

## Автоматическое обновление

По умолчанию Go переобучает модель каждый час. Новые события должны поступать в API: генератор не запускается автоматически.

Airflow опционален. Для него задайте `TRAIN_INTERVAL=0s` в `.env`, затем выполните:

```bash
docker compose --profile airflow up --build -d
docker compose exec airflow cat /opt/airflow/standalone_admin_password.txt
```

Интерфейс Airflow: http://127.0.0.1:8081, пользователь `admin`, пароль из команды. Включите DAG `recogo_retrain`, изначально он на паузе. Он запускается каждый час в начале часа по UTC. Отключайте встроенный планировщик при выборе Airflow, чтобы не создавать лишние версии.

Для Kubernetes используется CronJob; инструкция — `docs/KUBERNETES_RU.md`.

## Проверить откат

1. После первого успешного обучения ещё раз нажмите «Обучить новую версию».
2. В списке появятся две версии. Выберите первую и активируйте её.
3. Повторите запрос рекомендаций: в ответе будет ID выбранной версии.

Либо выполните `bin\recogo-windows-amd64.exe rollback`. Ошибка «no previous valid model» означает, что старой принятой версии ещё нет.

## Свои события

Отправляйте POST-запросы по примеру `docs/API_RU.md`. Для файла JSONL используйте:

```powershell
bin\recogo-windows-amd64.exe seed --file data\my_events.jsonl
bin\recogo-windows-amd64.exe train
```

Для обучения нужно минимум 20 событий и достаточное число пользователей с новыми покупками в хронологическом holdout. Стандартный `MIN_EVAL_USERS=3`. При нехватке оценочных пользователей кандидат будет отклонён; это нормальная проверка качества.

## Если не запускается

- Окна bat остаются открытыми: прочитайте ошибку над `pause`.
- Порт 8080 занят: остановите другой сервер либо задайте HTTP_ADDR и RECOGO_URL согласованно при ручном запуске. start_local.bat рассчитан на стандартный порт 8080.
- `timeout` на bbolt: другой процесс уже владеет тем же `var/recogo.db`.
- `no active model`: сначала загрузите события и успешно обучите модель.
- `event_id ... different payload`: нельзя менять содержимое уже принятого ID; для нового события нужен новый ID.
- Docker-ошибка: `docker compose ps -a`, затем `docker compose logs --tail 100`.
- `tracking_error` в отчёте: MLflow недоступен, локальная модель при этом может быть опубликована.
