# HTTP API

Локальный адрес: `http://127.0.0.1:8080`. JSON в UTF-8. Сервер ограничивает тело JSON 64 КиБ и отклоняет неизвестные поля.

## Событие

```http
POST /events
Content-Type: application/json

{
  "event_id": "event-0001",
  "user_id": "user-001",
  "product_id": "SKU-001",
  "type": "view",
  "timestamp": "2026-10-28T10:00:00Z"
}
```

`type`: view или purchase. Все идентификаторы — непустые строки до 128 байт. timestamp обязателен, UTC или RFC3339 с часовым поясом; будущее более чем на пять минут отклоняется.

Ответ локально: HTTP 201 `{"status":"stored","event_id":"event-0001"}`. Повтор идентичного события: 200 duplicate. Конфликт ID с другим содержимым: 409. В Kafka-режиме: 202 queued — событие записано в брокер, но может ещё не быть в хранилище. Конфликт там обнаруживает consumer и отправляет сообщение в DLQ. Проверка сохранения: `GET /events/event-0001`, 200 после сохранения, 404 до него.

## Рекомендации

```http
GET /recommendations?user_id=user-001&limit=5
```

```json
{
  "user_id": "user-001",
  "version": "version-id",
  "recommendations": [
    {"product_id": "SKU-004", "score": 1.23, "reason": "similar_to_history"}
  ]
}
```

Это иллюстрация формата, не измеренный результат. `limit`: 1–50. Для новых пользователей возвращается популярность. Для пользователя, увидевшего все товары доступного каталога в последних 100 событиях, список может быть пустым. Score персонального ранжирования и fallback имеют разные шкалы и не являются вероятностями.

## Обучение

```http
POST /admin/train
Authorization: Bearer recogo-local
Content-Type: application/json

{}
```

HTTP 200 с `accepted: true` означает принятую версию. HTTP 200 с `accepted: false` — завершённую оценку, не прошедшую quality gate. Недостаточный общий объём событий или конфликт операций даёт HTTP 409. CLI `train` при отклонении завершится ненулевым кодом, чтобы расписание заметило проблему.

## Версии и откат

`GET /versions` показывает сохранённые версии, active и valid. Откат:

```http
POST /admin/rollback
Authorization: Bearer recogo-local
Content-Type: application/json

{"version":"нужный ID"}
```

Пустая строка version выбирает ближайшую более старую валидную версию. Неизвестный или повреждённый артефакт не активируется. Можно явно указать любую сохранённую валидную версию, в том числе более новую.

## Служебные методы

| Метод | Назначение |
|---|---|
| GET / | Панель управления |
| GET /healthz | Процесс доступен |
| GET /readyz | Модель доступна для рекомендаций; иначе 503 |
| GET /report | Последний завершённый отчёт обучения |
| GET /metrics | Текстовые метрики Prometheus |

Чтение рекомендаций и приём событий в учебном стенде открыты. Bearer token защищает операции обучения/активации. Production-доступу нужны отдельная аутентификация пользователей, права, rate limit и TLS.
